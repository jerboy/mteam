# UI 设计规范

界面围绕内容和操作组织：中性灰白底色、深色正文、克制的品牌绿。搜索资源、查看进度和选择目录是主任务；配置和说明不争夺主要空间。

## 共享基础

颜色、间距、尺寸、圆角、阴影集中在 `extension/styles.css`。`popup.css`、`downloaders.css` 和 `tasks.css` 负责各自布局，使用同一组变量，不叠加旧版本覆盖规则。

| 用途 | 约定 |
| --- | --- |
| 页面背景 / 内容表面 | `#f5f5f7` / `#ffffff` |
| 正文 / 辅助文字 | `#202124` / `#646970` |
| 强调色 / 轻量选中背景 | `#10745c` / `#eaf4ef` |
| 删除操作 | `#b83b36` |
| 字体 | 系统字体；macOS 使用系统中文与西文字体 |
| 页面标题 / 弹窗标题 | 24 / 18 px，600–650 字重 |
| 列表标题 / 正文 / 标签 | 13–14 / 13 / 12 px；密集元信息与徽标最低 11 px |
| 工具栏 / 常规按钮 / 输入框 | 32 / 36 / 40 px 高 |
| 控件 / 菜单 / 分组 / 弹窗圆角 | 8 / 12 / 16 / 20 px |
| 间距 | 4、8、12、16、20、24、32 px，图标和文字允许小幅光学调整 |

主按钮只用于当前视图的明确动作，如搜索、保存和开始下载。列表操作采用轻量强调色。复制、刷新、关闭和翻页使用统一的线性图标，保留可读的无障碍标签；需要解释用途时提供悬停提示。

图标由 `icons.css` 中的本地 SVG mask 绘制，使用统一的 24 单位网格、1.7 描边和 18 px 显示尺寸，不依赖字体字符的外观或远程图标服务。

## 布局

- **搜索弹窗**：保持 780 × 590 px。工具栏、搜索和排序保持紧凑；资源列表占据剩余高度并独立滚动。标题、简介、元信息分层，复制操作收敛为图标。
- **标签页搜索**：内容最大宽度 1080 px，与弹窗共享行样式；窄窗口将操作放到标题下方。
- **设置**：最大宽度 720 px，按 M-Team、下载器、定期访问分组。输入框和行间距统一；清除、移除在左，取消和保存在右。
- **下载与目录**：480 px 弹窗，编辑路径保持默认入口。目录建议有文件夹图标和明确的选中状态，候选区独立滚动。
- **任务中心**：640 px 弹窗，列表在固定可用高度内滚动；进度、速度、状态与资源列表采用同一文字层级。删除按钮默认中性，悬停与确认操作使用红色。
- **详情、链接、删除确认**：统一弹窗边距、标题、关闭按钮和操作栏；内容超出可用高度时允许滚动。
- **资源简介**：Markdown 沿用正文层级；标题 16 / 14 / 13 px，代码和表格 12 px。简介、代码与宽表格各自在需要时滚动。图片直接作为预览入口，不增加单独的操作栏。
- **图片预览**：海报与简介图片共用一个模态层，初始按窗口尺寸完整容纳图片。多张时显示两侧箭头和序号，放大时显示可点击还原的比例；不增加说明栏或工具面板。滚轮围绕指针缩放，放大后可拖动；切图重置视图。Esc 或遮罩可关闭，返回原触发控件。

## 状态与可访问性

加载、空状态使用中性色，成功用绿色，异常用琥珀色，删除用红色。提示控制在操作需要的范围内，详细规则留在文档中。

交互元素保留清楚的键盘焦点；图标不作为唯一的可访问名称。状态同时提供文字，不单靠颜色。下载进度使用原生 `progress`，定期访问使用带 `switch` 语义的复选框。支持减少动态效果与强制对比色设置。

验证范围遵循项目约定：运行现有单元测试和源码静态检查，不连接真实账号，不执行浏览器功能测试或真实下载、删除操作。
