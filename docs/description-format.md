# 资源简介格式

## 调研结论

2026-10-21 查阅 [M-Team Wiki 的发种教程](https://wiki.m-team.cc/upload-tutorial)：

- 2.4 节使用嵌套的 `quote`、`b`、`color` 标签编写转载说明，并明确称其为 BBCode。
- 2.5 和 2.8 节通过 `img` 标签加入海报及截图。
- 2.7 和 3.7 节说明 MediaInfo 可能放在引用、专用标签或独立字段中，具体方式依站点规则而定。

因此扩展将 BBCode 作为简介的首选格式。该教程包含跨站通用说明，并非 M-Team 当前前端的完整标签规范；其中列举的扩展标签不能直接视为 M-Team 全部支持。未找到完整的官方标签表，也未通过真实账号接口或浏览器功能测试验证站点实现。

## 解析规则

识别到支持的成对 BBCode 或独立的 `br`、`hr` 标签后，整段简介按 BBCode 处理；不再解释 Markdown 的星号、下划线、标题、列表或缩进，避免改变文件名和 MediaInfo 的排版。普通文本保留空格、换行和字符原文。

没有可识别的 BBCode 时才使用 Markdown。检测时跳过 Markdown 的行内代码、围栏代码和反斜杠转义，便于显示介绍 BBCode 用法的 Markdown 文档。一旦选择 BBCode，代码示例应使用 `code`、`pre`、`nfo` 或 `mediainfo`，其内容保持原文。

| 内容 | 扩展支持的标签 |
| --- | --- |
| 引用 | `quote`、`quote=作者`，可嵌套 |
| 文字 | `b`、`i`、`u`、`s` / `strike` / `del`、`sub`、`sup` |
| 样式 | `color`、`size`、`font`，受限颜色、字号和等宽字体 |
| 链接、图片 | `url`、`url=地址`、`img`；忽略图片尺寸等属性，沿用统一预览 |
| 列表 | `list`、`list=1` / `list=a` 等、`ul`、`ol`、`li`、`[*]` |
| 对齐 | `left`、`center`、`right`、`align` |
| 原文块 | `code`、`pre`、`nfo`、`mediainfo` |
| 折叠 | `spoiler`、`hide`，可带标题 |
| 分隔 | `br`、`hr` |

这个表描述扩展的兼容范围，不声称所有标签都属于 M-Team 的官方语法。未知或不完整的标签尽量保留可读文字；过长或过深的内容会限长或回退为原文。字号限制在 11–20 px，字体和色彩不接受任意 CSS。站点 HTML 不进入 DOM，链接与图片限制为不含凭据的 HTTP / HTTPS 地址。

所有图片继续使用同一个预览器，支持缩放、拖动和左右切换。此调整不增加界面控件或说明区域。验证仅包含内存 DOM、词法解析和安全边界等单元测试。
